# REGLAS CRÍTICAS DE DESPLIEGUE - ESOL ENERGÍAS

## 1. DÓNDE ESTÁ ALOJADO CADA DOMINIO / PROYECTO
- **esolenergias.com** (y **www.esolenergias.com**):
  - **Hosting**: Hostinger Web Hosting compartido con CDN (IP FTP: `82.29.81.191` o `ftp://esolenergias.com`).
  - **NO es el VPS (`45.132.242.95`)**. Aunque el VPS tenga una carpeta `/var/www/esolenergias.com`, el DNS **NO** apunta ahí, sino a Hostinger CDN.
  - **MÉTODO OBLIGATORIO DE DEPLOY**: 
    ```powershell
    powershell -ExecutionPolicy Bypass -File .\ftp_deploy.ps1
    ```
    o mediante:
    ```bash
    npm run deploy
    ```
  - **DESTINO FTP**: La raíz `/` del FTP (`u821937813.esolenergias.com`). Nunca subir a `/public_html/`.

- **controlenergias.com**:
  - **Hosting**: Este proyecto es una aplicación **COMPLETAMENTE INDEPENDIENTE**.
  - **NUNCA mezclar** código, assets o dist de ESOL con `controlenergias.com` ni con su carpeta `/var/www/controlenergias`.

## 2. REGLA ESTRICTA PARA CUALQUIER AGENTE / ASISTENTE
- **NUNCA** ejecutar scripts dirigidos al VPS (`scripts/deploy_vps.cjs`) cuando el usuario pida desplegar o actualizar `esolenergias.com`.
- **SIEMPRE** usar `powershell -ExecutionPolicy Bypass -File .\ftp_deploy.ps1` (o `npm run deploy`).
- Tras cada deploy, validar automáticamente con petición HTTP a `https://www.esolenergias.com` que los hashes del bundle `index.html` coinciden con los de `dist/index.html`.
